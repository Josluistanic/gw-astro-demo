# Astro Clay Theme - CI/CD Demo for CPanel

This project uses [Astro's Clay theme](https://astro.build/themes/details/clay/) with only a title modification. The project serves as an example of CI/CD implementation on shared hosting with CPanel, which is why it contains a `.github/workflows/deploy.yml` file.

There are no significant changes to the template/theme.

This project was created for a YouTube video (link pending).
